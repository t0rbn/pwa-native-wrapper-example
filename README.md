# PWA + Android Webview Wrapper App
<https://t0rbn.github.io/pwa-native-wrapper-example/pwa/index.html>

This repo contains a simple [PWA](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps) and an [Android WebView App](https://developer.android.com/develop/ui/views/layout/webapps/webview) displaying the PWA in a native wrapper to compare the look and feel of an in-browser web app vs. an installed PWA vs. a native app.
